# IAgro_prot-tipo_ML_and_software
Protótipo experimental de inteligência artificial para classificação acústica na avicultura, utilizando machine learning para analisar sons de frangos de corte e explorar a identificação de padrões associados a alterações nas aves. Desenvolvido inicialmente com uma base de dados pública, como etapa de pesquisa e evolução da IAgro.
